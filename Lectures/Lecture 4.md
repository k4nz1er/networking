# Network Architectures

## Three-tier architecture
- core: web servers, databases, applications (many people need access to this)
- distribution: midpoint between the core ande the users
- access: users connect, end stations, printers

## Two-tier model
- collapsed core: good fit for smaller organizations
- combine core and distribution layers
- differences over three-tier

## Traffic flows
- east-west: between devices in the same data center, relatively fast response times
- north-south: different security posture than east-west
