# Other Useful Protocols

ICMP (Internet Control Message Protocol) - for your network devices

GRE (Generic Routing Encapsulation) - the "tunnel" between two endpoints

VPN-s technologies: site-to-site, IPSec


# Network Communication

1. **Unicast** - one-to-one
2. **Multicast** - one-to-many-of-many, dynamic routing updates
3. **Anycast** - one-to-one-of-many, used in IPv4 and IPv6
4. **Broadcast** - one-to-all, **not** used in IPv6


# Wireless Networking

Wireless standards (802.11)

802.11a - 5 GHz - 6-54 Mbit/s
802.11g - 2.4 GHz - 6-54 Mbit/s

**LTE** (Long Term Evolution)
- 4G
- Converged standard (GSM and CDMA providers)
- Based on GSM and EDGE (Enhanced Data Rates for GSM Evolution)
- 150 Mbit/s

**LTE-A** (LTE Advanced)
- 300 Mbit/s


# Ethernet Standards

The IEEE 802.3

1000BASE-T (copper) - Gigabit Ethernet - 1 gigabit per second
10GBASE-T - 10 Gigabit Ethernet - 10 gigabits per second
1000BASE-SX (fiber) - Gigabit Ethernet - 1 gigabit per second

1000BASE-T :
1000 - is speed
BASE - is baseband
T - is media type
